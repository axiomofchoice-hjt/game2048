# 2048 · React 复刻

使用 **React + Vite** 复刻的经典 2048 小游戏。

## 功能

- 标准 4×4 棋盘、合并与计分规则
- 键盘操作：方向键 / WASD
- 鼠标 / 触屏滑动操作（桌面端用鼠标拖动，移动端用手指滑动）
- 得分为 2 时的随机生成（90% 出 2，10% 出 4）
- 达成 2048 胜利，可「继续挑战」；无法移动时游戏结束
- 历史最高分本地持久化（localStorage）
- 经典配色与方块滑动 / 合并动画

## 项目结构

```
src/
  game.js      # 纯函数核心逻辑（滑动、合并、生成、胜负判断）
  App.jsx      # 组件：状态、键盘/触屏事件、UI 渲染
  main.jsx     # 入口
  styles.css   # 样式与动画
```

## 使用

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务器（http://localhost:5173）
npm run build   # 构建生产包到 dist/
npm run preview # 预览生产构建
```

## 规则简述

滑动方向使用边相邻的相同数字方块合并为它们的和（每个方块每次只合并一次）。每次有效移动后随机生成一个新方块（2 或 4）。当棋盘填满且无相邻可合并方块时游戏结束。
